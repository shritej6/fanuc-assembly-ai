# T13 RT-DETR and Wrist Classifier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, verify, and launch reproducible RT-DETR and 30-class wrist-classifier training on the approved Rosie synthetic data.

**Architecture:** A pure-Python preparation layer validates completed chunks, freezes scene-level splits, and emits immutable detector/classifier manifests with provenance. Thin PyTorch/Transformers adapters consume those manifests; evaluation writes measured COCO and classifier/look-alike metrics. Slurm wrappers enforce V100-safe precision, checkpoint resume, and a smoke gate before full training.

**Tech Stack:** Python 3.12, Pillow, NumPy, PyTorch/torchvision, Hugging Face Transformers RT-DETR, Accelerate/Trainer, TorchMetrics/pycocotools, Slurm on Rosie V100.

**Spec:** `docs/PLAN.md`

## Global Constraints

- Detector is RT-DETR; do not substitute Faster R-CNN or YOLO.
- Detector keeps all 30 contract object IDs separate and adds the three measured foreign distractor labels.
- Wrist classifier has exactly the 30 contract object IDs; geometrically identical IDs are not merged.
- Detector sources are A/F/G; classifier sources are B/H/K per newest `coord/HANDOFF.md`.
- Read only complete `synthetic/<set>/chunk_NNNN` chunks with passing `_QA.json`; never traverse `rejected`, `superseded`, or real-cell data.
- Include only Cosmos files marked `accepted: true` in `_COSMOS.json`; use Cosmos as train-only augmentation and keep it in the native scene's split.
- Full manifests require a 10-20% accepted Cosmos share for every requested set; native-only is allowed only for the bounded smoke run.
- Split by `(set, scene index)`, never image path, so cameras and native/Cosmos variants cannot cross splits.
- Use FP16 on V100; BF16 and TF32 are disabled.
- Record git commit, taxonomy hash, manifest hash, split seed, pretrained revision, and resolved package versions.
- Real-cell images are evaluation only and never enter training manifests.

## Review Focus

- A passing `_QA.json` whose labelled/expected counts disagree must be rejected, not trusted.
- An accepted Cosmos entry with a missing file, or an orphan Cosmos file without acceptance evidence, must fail or be excluded explicitly.
- A declared wrist target that is fully occluded and absent from camera annotations must be skipped and counted, never replaced by the whole frame.
- Bounds at the right/bottom image edge must preserve positive COCO width/height and valid classifier crops.
- A manifest or taxonomy change must block checkpoint resume instead of silently changing class indices.
- Empty classes or missing train/validation/test coverage must stop full training with an actionable error.
